# Лабораторна робота №2

**Виконав:** Пирин Віталій Орестович  
**Група:** ІР-12  
**Дисципліна:** Алгоритмізація та програмування, частина 2  
**Варіант:** 1  
**Рівень:** 3  

## Умова:
Зоомагазин займається продажем хом'ячків. Це мирні домашні істоти, проте, як виявилося, вони мають цікаву харчову поведінку. Для того, щоб прогодувати хом'ячка, який живе наодинці, потрібно **H** пакетів корму на день. Однак, якщо кілька хом'яків живуть разом, у них прокидається жадібність. У такому випадку кожен хом'ячок з'їдає додатково **G** пакетів корму в день за кожного сусіда.

Реалізуйте функцію, яка поверне число — максимальну кількість хом'яків, яку ви можете прогодувати. 

**Вхідні параметри:**
* **S** — ваш денний запас їжі.
* **C** — загальна кількість хом'ячків у магазині.
* **hamsters** — матриця, де перший стовпчик — денна норма корму (H), другий — рівень жадібності (G).

---

## Приклади:
1. **S = 7, C = 3**, hamsters = `[[1, 2], [2, 2], [3, 1]]`  
   *Результат:* **2**
2. **S = 19, C = 4**, hamsters = `[[5, 0], [2, 2], [1, 4], [5, 1]]`  
   *Результат:* **3**
3. **S = 2, C = 2**, hamsters = `[[1, 50000], [1, 60000]]`  
   *Результат:* **1**

---

## Реалізація та перевірка:
Для оптимізації розв'язання задачі використано:
* **Бінарний пошук** по відповіді — для швидкого знаходження максимальної кількості.
* **Radix Sort (Порозрядне сортування)** — для швидкого підрахунку витрат на годівлю.


Для перевірки виконання роботи використано бібліотеку **unittest**. Перевірено роботу функції на прикладах, наведених вище, а також на великих значеннях жадібності.
