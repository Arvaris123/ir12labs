# Лабораторна робота №1

**Виконав:** Пирин Віталій Орестович  
**Група:** ІР-12  
**Дисципліна:** Алгоритмізація та програмування, частина 2  
**Варіант:** 1  
**Рівень:** 2  

---

### Умова:
Напишіть функцію для управління роботом-садівником, який обходить прямокутну ділянку (матрицю) за траєкторією "змійка". Робот повинен збирати/садити врожай, враховуючи наступні часові обмеження:
* Кожен крок до сусідньої клітинки в межах одного ряду займає **1 хвилину**.
* Перехід з кінця одного ряду на початок наступного займає **4 хвилини**.
* Робот може працювати безперервно не більше **30 хвилин**, після чого йому потрібна перерва (час після перерви скидається до 0, або до 4, якщо зупинка сталася під час переходу між рядами).

**Функція повинна повертати:**
1. Повну послідовність пройдених клітинок (маршрут змійкою).
2. Загальну кількість зупинок на перерву.
3. Список значень (історію), що показує загальну кількість зібраних гарбузів на момент кожної зупинки.
4. Фінальну суму всіх значень у матриці.

---

### Реалізація та перевірка:
Для перевірки виконання роботи реалізованого алгоритму використано бібліотеку `unittest`. Перевірено наступні сценарії:
* **Матриця 4x4:** повна перевірка маршруту, суми та ліміту часу.
* **Матриця 4x5:** перевірка коректності обходу "змійкою" для прямокутної ділянки.
* **Матриця 1x6 (один стовпець):** перевірка роботи алгоритму, коли в рядку лише один елемент.
* **Матриця 2x4:** перевірка базового переходу між рядами.
