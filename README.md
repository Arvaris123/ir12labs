## Умова
Індіана Джонс проходить крізь прямокутний коридор з крихких плит. На кожній плиті написана одна літера. Необхідно знайти **кількість різних шляхів** для виходу з коридору.

Дано:
- Файл `ijones.in` з розмірами коридору та сіткою літер
- Ширина `W` та висота `H` коридору (1 ≤ W, H ≤ 2000)
- Кожна клітинка містить малу латинську літеру

Правила руху:
- Починати можна з **будь-якої** клітинки лівого стовпця
- Виходом є **верхня права** та **нижня права** клітинки
- Кожен крок — тільки **вправо**
- Завжди можна перейти на **сусідню** праву клітинку
- Можна **стрибнути** на будь-яку праву клітинку з **такою самою літерою**
---
## Реалізація та перевірка
### Алгоритм динамічного програмування
Реалізовано алгоритм підрахунку шляхів за допомогою **динамічного програмування**, що рухається **справа наліво**.
### Основна логіка
1. Починаємо з правого стовпця — виходи отримують значення 1, решта 0
2. Рахуємо `total[ch]` — суму шляхів для кожної літери правіше
3. Йдемо справа наліво по стовпцях:
   - `f[r]` = крок на сусідню праву клітинку
   - `total[ch]` = стрибок на таку саму літеру правіше
   - Якщо сусідня має таку саму літеру — віднімаємо щоб не рахувати двічі
4. Повертаємо суму шляхів лівого стовпця
### Тести
Проведено модульне тестування:
- Тест на сітці 3x3: очікуваний результат **5**
- Тест на одному рядку: очікуваний результат **2**
- Тест на сітці 7x6 з однаковими літерами: очікуваний результат **201684**
