## Умова

Створити функцію на мові програмування Python, яка приймає дві стрічки: `haystack` (довільний текст) та `needle` (шукана стрічка). Програма повинна знайти **індекси всіх входжень** стрічки `needle` в стрічці `haystack` та повернути їх список, використовуючи **метод скінченних автоматів** для пошуку підстрічки у стрічці.

---

## Реалізація та перевірка

### Алгоритм скінченних автоматів

Реалізовано алгоритм пошуку підстрічки на основі **скінченного автомата (Finite Automaton String Matching)**.

### Основна логіка

1. Будуємо **таблицю переходів** `table[state][ch]` для всіх станів від `0` до `m` і всіх символів алфавіту
2. Для кожного стану і символу знаходимо найдовший префікс `needle`, який є суфіксом `needle[:state] + ch`
3. Проходимо по `haystack` зліва направо, оновлюючи поточний стан через таблицю переходів
4. Якщо стан досяг `m` — знайдено входження, записуємо індекс початку

### Тести

Проведено модульне тестування:

- Пошук з кількома входженнями: `find_all("abracadabra", "abr")` → очікуваний результат **[0, 7]**
- Пошук з перекриттями: `find_all("aaaa", "aa")` → очікуваний результат **[0, 1, 2]**
- Підстрічка відсутня: `find_all("hello", "xyz")` → очікуваний результат **[]**
