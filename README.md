  ## Умова

  Алгоритм **Flood Fill** (також відомий як початкове заповнення) — це алгоритм, який визначає область, в яку входить певний вузол у багатовимірному масиві.

  Він використовується в інструменті заповнення «ковша» програми малювання, щоб заповнити з'єднані області, однаково забарвлені області іншим кольором, а також у таких іграх, як **Go** та **Minesweeper**.

  Застосування для заповнення кольором певної обмеженої області також називається **заливкою межі**.

  Алгоритм заливки приймає три параметри: **початковий вузол**, **цільовий колір** і **колір заміни**.
