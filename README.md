## Умова

До мерії міста Венеції потрібно допомогти прокласти оптоволоконний інтернет на острови.

Місто складається з островів, з'єднаних мостами. Необхідно знайти **мінімальну сумарну довжину кабелів**, яку потрібно прокласти, щоб кожен острів був з'єднаний з кожним іншим (безпосередньо або через інші острови).

Дано:
- Файл `islands.csv` з матрицею суміжності
- Елемент `[i][j]` — відстань між островами `i` та `j`
- Кількість островів `N` (1 ≤ N ≤ 100)

Потрібно знайти мінімальну довжину підводних кабелів.

## Реалізація та перевірка

### Алгоритм Прима

Реалізовано алгоритм побудови мінімального кістякового дерева (MST) з матриці суміжності.

### Основна логіка

1. Зчитуємо матрицю суміжності з CSV-файлу
2. Запускаємо алгоритм Прима:
   - Починаємо з вузла 0
   - На кожному кроці додаємо найближчий вузол поза деревом
   - Сумуємо ваги обраних ребер
3. Повертаємо загальну вагу MST

### Тести

Проведено модульне тестування:
- Тест на двох островах: очікуваний результат **5**
- Тест на чотирьох островах: очікуваний результат **6**
- Тест на читання з CSV-файлу: очікуваний результат **3**
