## **Умова:**
Для заданого червоно-чорного дерева реалізувати чергу з пріоритетами, в якій підтримуються наступні операції:
- **Вставка** елементів з визначеними значенням та пріоритетом.
- **Видалення** елемента з найвищим пріоритетом.
- **Перегляд** елемента з найвищим пріоритетом.

## **Реалізація та перевірка:**
1. **Вставка та видалення елементів:**  
   Перевірка роботи методів `insert` та `extract_max`.
   
2. **Перегляд елемента:**  
   Перевірка роботи методу `peek`.
   
3. **Порожня черга:**  
   Тест на порожню чергу.
   
4. **Однакові пріоритети:**  
   Тест на елементи з однаковими пріоритетами.
