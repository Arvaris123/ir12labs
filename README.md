## Умова:
Для заданого бінарного дерева та конкретної вершини в цьому дереві реалізуйте функцію пошуку наступного елемента під час серединного проходу (**in-order traversal**). Наступник — це вузол, який має значення більше за заданий вузол і знаходиться найближче до нього при серединному обході.

### Додаткові завдання (реалізовані):
* **Клас BinaryTree:** реалізовано структуру вузла з посиланнями на `left`, `right` та `parent`.
* **Робота з файлами:** додано функції `write_tree` та `read_tree` для збереження структури дерева у файл `tree_output.txt` та його відновлення.
* **Інвертований обхід:** реалізовано функцію `inorder_invert` для обходу дерева у зворотному порядку.
* **Візуалізація:** додано функцію `display_upside_down` для графічного відображення ієрархії дерева в консолі.

## Реалізація та перевірка:
Для перевірки виконання роботи реалізованого алгоритму використано бібліотеку **unittest**. Перевірено наступні сценарії:

* **Пошук наступника "вгору":** випадок, коли наступником є один із предків вузла.
* **Пошук наступника "вниз":** випадок, коли наступник знаходиться у правому піддереві вузла.
* **Коректність відновлення:** перевірка побудови дерева з файлу за допомогою `level-order` представлення.
* **Складна структура:** тестування на кастомному дереві з великою кількістю рівнів та відгалужень.
