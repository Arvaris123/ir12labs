## Умова

Задача про оптимальне розташування ігрового сервера в мережі комп'ютерів. 

Необхідно знайти вузол мережі, де розташовувати сервер так, щоб **максимальна затримка від сервера до найдальшого клієнта була мінімальною**.

Дано:
- Граф з вузлами (комп'ютери)
- Ребра з вагами (затримка в мс)
- Список клієнтів на певних вузлах

Потрібно визначити, на якому вузлі розташувати сервер для оптимізації з'єднання з усіма клієнтами.

## Реалізація та перевірка

### Алгоритм Дейкстри

Реалізовано алгоритм знаходження найкоротших шляхів від одного вузла до всіх інших з використанням пріоритетної черги.

### Основна логіка

Для кожного можливого місця сервера (крім місць клієнтів):
1. Запускаємо Дейкстру від цього вузла
2. Знаходимо максимальну затримку до всіх клієнтів
3. Вибираємо місце з мінімальною максимальною затримкою

### Тести

Проведено модульне тестування на прикладах з завдання:
- Тест на прикладі з PDF (6 вузлів, 3 клієнти): очікуваний результат **100**
- Тест на простому графу (3 вузли, 2 клієнти): очікуваний результат **7**
